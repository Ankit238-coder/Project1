# EV Market Performance & Insights (Tableau)

An educational Tableau Public project exploring EV sales, vehicle categories, battery technology, driving range, manufacturing countries, and customer ratings.

## Dataset notice
The included CSV is synthetic demonstration data. It is not verified real-world market data. Do not present results as factual global EV market statistics.
